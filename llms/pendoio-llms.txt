# Pendo.io

> Pendo is a product-experience and product-analytics platform. Its Engage API gives programmatic access to the pages, features, guides, visitors, accounts, segments, reports, and metadata the Pendo agent collects, plus a MongoDB-like Aggregation API for structured event queries. Authentication uses a per-subscription integration key in the x-pendo-integration-key header (OAuth 2.0 is also published via RFC 8414 metadata).

## APIs
- [Engage API (docs)](https://engageapi.pendo.io/): REST API for pages, features, guides, visitors, accounts, segments, reports, metadata, and aggregations. Base URL https://app.pendo.io/api/v1.
- [Feedback API](https://feedbackapi.pendo.io/): separate Postman collection for Pendo Feedback.
- [Developer Portal](https://developers.pendo.io/): Pendo developer documentation and agent SDK updates.
